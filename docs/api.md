# Carve 0.2 PHP API reference

Generated by `php scripts/api-reference.php` from the public classes in
`tests/PublicApi/PublicSurface.php`; do not edit by hand. Every other class under `MarkupCarve\Carve` is
internal. Classes under "Extensions (provisional)" follow the extension host of the specification, which may
change in 0.2.x. See [the guide](README.md) for examples and [the migration guide](migration.md) for 0.1 calls.

## Entry

### `MarkupCarve\Carve\Carve`

Class. The public entry of the 0.2 engine (tooling.md C2-T-005): parse, render, lint, format and write, HTML import, tree JSON, include dependencies and the output writers. Every call validates its options and throws only errors that implement `CarveException`.

- `static parse(string $source, array $options = []): Node`: Parse and resolve: the tree of a source.
- `static parseWithDiagnostics(string $source, array $options = []): ParseResult`: Parse and resolve, with the entries of the parse channel (C2-A-173).
- `static parseWithLayout(string $source, array $options = []): LayoutResult`: Parse and resolve, with the source-layout record of the input (C2-L-001, C2-L-003: the tree is the same).
- `static supportsIncrementalParagraphReuse(): bool`
- `static createEditorSession(string $source, array $options = []): EditorSession`: Start a source-authoritative editor session with byte-range edits.
- `static validateLayout(string $json, ?array $tree = null): array`: Reads a source-layout record as JSON, refusing what C2-L-008 and C2-L-058 refuse.
- `static renderWithDiagnostics(Node|array|string $input, array $options = []): RenderResult`: Render, with the entries of the parse and the render-loss channels (C2-A-173). A tree has no parse entries.
- `static renderWithDocumentTransforms(Node|array|string $input, array $transforms, array $options = []): RenderResult`: C2-X-053 to C2-X-055: run named host passes on a copied resolved view before HTML rendering.
- `static toHtml(string $source, array $options = []): string`: Carve source to HTML; `render()` takes a tree as well.
- `static toJson(string $source, array $options = []): string`: Carve source to the bare tree as JSON (C2-A-012), with positions.
- `static lint(string $source, array $options = []): array`: C2-W-103, C2-W-109: the lint findings of a source, with the catalog messages, byte ranges and tree paths. Options: `rules` (rule id to `on` or `off`), `platforms` (`['github']`), `upgrade` (`true` turns on the 0.1 migration notices, which also run for a document whose line-1 frontmatter declares `carve: 0.1`; C2-W-156), `headingIds` (C2-T-042) and `includes`, which lints the included files too (C2-N-085). Nothing of lint runs unless this is called.
- `static importHtml(string $html, array $options = []): ImportResult`: The HTML importer (import-html.md): the tree, the canonical source and the diagnostics of an HTML string. Options: `adapter` (C2-M-102), `rawHtml` (C2-M-066), `labels` (C2-M-101), `listTable` (C2-M-112) and `strictLosses` (C2-M-082). Needs `ext-dom`.
- `static includeDependencies(Node|string $input, array $options = []): array`: C2-N-083: the includes of a tree in tree order. Source is parsed first with `$options`, which then needs `includes` for any include to be read.
- `static selectIncludeRegion(string $source, string $name, string $mode): array`: C2-N-037 to C2-N-041: where the region `$name` of an included file's source lies, as an include directive in `$mode` (`carve` or `code`) selects it. `start` and `end` are the one-based first and last selected line; an empty region has `end` one less than `start`. Where the directive would report `include-region-invalid`, `ok` is false.
- `static write(Node|array $tree, ?array $layout = null, array $options = []): string`: C2-W-001: the canonical source of a tree; throws `CarveWriteError` when the tree holds what no source spells.
- `static writeWithDiagnostics(Node|array $tree, ?array $layout = null, array $options = []): WriteResult`: `write()` with the writer losses as diagnostics instead of a `CarveWriteError` (C2-W-134).
- `static format(string $source, array $options = [], ?array $layout = null): string`: C2-W-100: parse and write again.
- `static formatWithDiagnostics(string $source, array $options = [], ?array $layout = null): WriteResult`: `format()` with the writer losses as diagnostics (C2-W-134).
- `static render(Node|array|string $input, array $options = []): string`: C2-T-005 `render`: the HTML of Carve source or of a tree. A tree is a `Node` of `parse()` or `decodeTree()`, or the decoded AST JSON as an array; it is validated (C2-A-188) and resolved again with the render options on a copy, so the caller's tree is not changed.
- `static tryRenderHtmlStreaming(string $source, callable $sink, array $options = []): string`: Render the complete document before delivering it to the sink. A failed render never calls the sink.
- `static importDocument(string $input, array $options = []): ImportResult`: C2-T-005 `importDocument`: the importer for `from`: `html` (the default), or `markdown`, `gfm` and `djot` through the HTML hub. `rawHtml` applies to HTML only; a hub import always keeps the raw content of its input.
- `static positionOf(string $source, mixed $offset): array`: C2-T-041: the line and column of C2-T-019 for a range that starts at the UTF-8 byte offset `$offset` of `$source`.
- `static version(): ?string`: The version of this package as Composer installed it, or null outside a Composer install.
- `static headingId(string $text, array $options = []): ?string`: The id the `headingIds` option generates for a heading with the plain text `$text` (C2-H-022, C2-H-143 to C2-H-148), or null under `off`. Each call stands alone: no `-2` suffix of a repeated id (C2-H-024).
- `static sourceFingerprint(string $source): string`: The fingerprint of a source: `sha256:` and the SHA-256 of its bytes.
- `static treeFingerprint(Node $tree): string`: The fingerprint of a tree: `sha256:` and the SHA-256 of `encodeTree($tree)`.
- `static diffTree(Node $a, Node $b): array`: The JSON Patch (RFC 6902) that turns the encoded tree `$a` into the encoded tree `$b`, with RFC 6901 paths. Object values are `stdClass`, as `json_decode()` gives them.
- `static applyPatch(Node $tree, array $patch, array $options = []): Node`: Applies a JSON Patch to the encoded tree and decodes the result; `$tree` is not changed.
- `static encodeTree(Node $tree): string`: C2-A-012: the bare tree as JSON, without positions where the tree came from JSON without them.
- `static encodeEnvelope(Node $tree): string`: C2-A-012, C2-A-013: the tree in its envelope, for a storage or process boundary.
- `static decodeTree(string $json, array $options = []): Node`: C2-A-188: reads the JSON of a 2.0 tree or envelope.
- `static migrateTree(array|string $tree, array $options = []): array`: C2-A-176 to C2-A-180: migrate a stored 1.x or retired draft tree before strict 2.0 decoding.
- `static validateTree(Node|array $tree, array $options = []): void`: C2-A-188: returns when the tree passes the schema and the reader checks, and throws the refusal otherwise.
- `static plainText(Node|array $nodes): string`: C2-H-143: the plain text of a node or a node list of a tree, the text `RenderHost::$plainText` gives a renderer. A block node gives the plain text of its children.
- `static tableGrid(Node $table): array`: The cell grid of a `table` node with its spans filled in, for an output that cannot express rowspan and colspan: per row in order (head, body, foot), the row, its group and, per column, the cell that occupies the slot. A cell spanning columns or rows fills every slot it covers and a slot no cell reaches is null; every row has as many columns as the widest.
- `static safeCodeFence(string $content, string $marker = '`'): string`: The shortest code fence of `$marker` (three at least) that is longer than every run of it opening a line of `$content`, so the content cannot close the fence.
- `static writers(): WriterRegistry`: A writer registry with the `html` and `carve` targets and the exports `markdown`, `plain` and `ansi`; register further `OutputWriter`s on it.
- `static writeTo(string $target, Node $tree, array $options = [], ?WriterRegistry $registry = null): string`: Writes a tree with the writer of `$target`, from `$registry` or from `writers()`.

## Tree

### `MarkupCarve\Carve\Node`

Class. One node of the AST 2.0 tree (C2-A-021). The type name is the schema type; fields other than `type`, `children` and `pos` live in `$f` under their schema names. Positions are byte offsets into the source; lines and columns are derived when the tree is encoded (C2-A-140).

- `static at(string $type, int $start, int $end): Node`
- `static text(string $value, int $start, int $end): Node`

## Output writers

### `MarkupCarve\Carve\Output\OutputWriter`

Interface. A writer of one output target. It reads the resolved tree and an option map; it validates its own options and throws `OptionError` for one it does not take.

- `target(): string`: The target name, unique in a registry: `html`, `carve`, `markdown`, `plain`, `ansi` or a host's own.
- `write(Node $tree, array $options = []): string`

### `MarkupCarve\Carve\Output\WriterRegistry`

Class. The output targets by name. `Carve::writers()` gives a registry with `html`, `carve` and the exports `markdown`, `plain` and `ansi`. A registry is a plain object: no state is shared between instances.

- `register(OutputWriter $writer)`: Adds a writer; a target that is already registered is replaced. Only the export of a reserved target (`markdown`, `plain`, `ansi`) may take it.
- `has(string $target): bool`
- `get(string $target): OutputWriter`
- `targets(): array`
- `write(string $target, Node $tree, array $options = []): string`

### `MarkupCarve\Carve\Output\HtmlWriter`

Class. The `html` target: `Carve::render()` of a tree, with the render options.

- `target(): string`
- `write(Node $tree, array $options = []): string`

### `MarkupCarve\Carve\Output\CarveWriter`

Class. The `carve` target: `Carve::write()` of a tree, with `alignTables` and `extensions`.

- `target(): string`
- `write(Node $tree, array $options = []): string`

## Editor APIs

### `MarkupCarve\Carve\Ast\EditorSession`

Class. Source-authoritative UTF-8 editor state. Edit ranges are byte offsets.

- `snapshot(): array`
- `update(array $changes): array`: Apply sorted, non-overlapping changes in the previous snapshot.

### `MarkupCarve\Carve\ProseMirror\ProseMirrorRenderer`

Class. ProseMirror JSON of a Carve 0.2 tree, in the schema of the carve-grammars Tiptap kit (`tiptap/tree.js`).

- `blanked(): array`: The denied destinations the last `render()` kept out of the editor's link and image attributes.
- `render(Node|array $tree): array`: The ProseMirror `doc` of `$tree`.
- `renderJson(Node|array $tree): string`: `render()` as JSON, for the editor's `setContent()`.
- `renderSource(string $source, array $options = []): array`: The ProseMirror `doc` of Carve source.

### `MarkupCarve\Carve\ProseMirror\ProseMirrorToCarve`

Class. Carve from ProseMirror JSON in the schema of the carve-grammars Tiptap kit (`tiptap/tree.js`).

- `pointerFor(string $treePath): ?string`: The ProseMirror JSON pointer of the node at `$treePath` in the last `toTree()` or `convert()`, such as the `path` of a lint finding on the saved source: the pointer of the node or mark it came from, or of its nearest ancestor that came from one (a span mark cell, a table section). Null when no ancestor did.
- `ignoredAttributes(): array`: The attributes the last `toTree()` or `convert()` did not read, each with the JSON pointer of its node or mark in the saved document. A host that must not lose editor state can refuse a save when this is not empty.
- `static carveTypeFor(string $proseMirrorName): ?string`: The Carve tree type of a ProseMirror node or mark name of the kit, or null when the kit does not map it. `carveBlock` and `carveInline` carry a whole node of any type and give null.
- `static proseMirrorNames(): array`: Every ProseMirror node and mark name the kit maps to one Carve tree type, as name => tree type.
- `convert(array|string $doc, array $options = []): string`: The canonical Carve source of a ProseMirror document.
- `toTree(array|string $doc): array`: The Carve 0.2 `document` tree of a ProseMirror document, as decoded AST JSON.
- `toTreeWithOrigins(array|string $doc): array`: The tree; for each top-level block the index of the loaded block it came from (null for a block the editor added); and by tree path, the JSON pointer of the ProseMirror node or mark each tree node came from.

- `static headingReference(string $cssClass = 'heading-ref'): ExtensionDefinition`: Gives the class `heading-ref` to each reference link a heading resolves (`[Heading][]`, `[text][Heading]`, C2-H-083). The 0.1 `[[Heading]]` spelling is gone: 0.2 adds no delimiter for it (C2-X-013, C2-X-057).

  0 => 'javascript',
  1 => 'vbscript',
  2 => 'data',
  3 => 'file',

- `static autolink(array $allowedSchemes = array (
  0 => 'https',
  1 => 'http',
  2 => 'mailto',

- `static tocPlacement(): ExtensionDefinition`: Writes a table of contents at each `toc` directive, claimed as `carve.tocPlacement`; its headings window comes from `{depth=N}` or `{from=X to=Y}`, and like `tableOfContents()` it lists only the headings a section wraps. Its renderer is registered through `renderers` (`'carve.tocPlacement' => 'standard'`); without that entry the fallback is written and reported (C2-X-052).
